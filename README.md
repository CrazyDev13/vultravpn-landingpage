# VultraVPN Website

React landing page built with Vite, ready for deployment to Vercel.

## Available scripts

- `npm install` - install dependencies
- `npm run dev` - start local development server
- `npm run build` - create production build in `dist/`
- `npm run preview` - preview production build locally

## Deploy to Vercel

1. Connect this repository to Vercel.
2. Ensure the project root is set to the `Website` folder.
3. Place your `appicon.png` inside the `public/` folder so it is served as the app icon.
4. Vercel will use the existing `package.json` and `vercel.json` build settings.
